# 睡眠段階クラスタリング分析

## 1. 概要

本プロジェクトでは、睡眠中に記録された脳波（EEG）の周波数特徴量を用いて、睡眠段階のクラスタリングを行った。

KMeansによる教師なし学習を用い、特徴量の違いが分類結果に与える影響を比較した。また、睡眠段階の移行や時間経過に伴う脳波の変化についても分析した。

## 2. 背景・目的

睡眠は、覚醒（W）、浅い睡眠（N1・N2）、深い睡眠（N3）、レム睡眠（REM）などの段階に分類される。

各睡眠段階では脳波の特徴が異なるため、周波数成分を分析することで睡眠状態の違いを捉えられる可能性がある。

本プロジェクトでは、脳波から抽出した特徴量を用いて、睡眠段階の違いを教師なし学習でどの程度捉えられるかを検証することを目的とした。

## 3. 使用データ

PhysioNetで公開されているSleep-EDF DatabaseのSleep Cassetteデータを使用した。

主に以下の情報を分析対象とした。

- EEG（Fpz-Cz）
- 睡眠段階のアノテーション
- 30秒ごとのエポック

睡眠段階のラベルは、クラスタリングの学習には使用せず、結果の評価や補足分析に使用した。

### データの取得方法

本プロジェクトでは、PhysioNetが公開するSleep-EDF Database ExpandedのSleep Cassetteデータを使用した。

使用ファイルは以下のとおり。

- `SC4001E0-PSG.edf`：睡眠中の生体信号データ
- `SC4001EC-Hypnogram.edf`：睡眠段階のアノテーション

データはPhysioNetのSleep-EDF Database Expandedから取得できる。

取得したファイルは、プロジェクト内の `data/raw/` に配置する。

なお、元データはGitHubには含めていない。

## 5. 分析方法

### 5.1 特徴量の抽出

EEGデータを30秒単位に分割し、周波数解析によって以下の特徴量を抽出した。

- Delta（デルタ波）
- Theta（シータ波）
- Alpha（アルファ波）
- Beta（ベータ波）

各周波数帯域の絶対パワーと相対パワーを算出し、さらにAlpha/Theta比を特徴量として追加した。

### 5.2 クラスタリング

KMeansを用いてクラスタリングを行った。

特徴量の組み合わせやクラスタ数を変更し、分類結果の違いを比較した。

### 5.3 評価方法

クラスタリング結果と実際の睡眠段階の一致度を、Adjusted Rand Index（ARI）を用いて評価した。

ARIは、クラスタリング結果と正解ラベルの一致度を、偶然の一致を考慮して評価する指標である。

## 6. 分析結果

### 6.1 クラスタリング結果

5クラスタで比較した結果、以下のARIが得られた。

| 使用した特徴量 | ARI |
|---|---:|
| 絶対パワー4種類 | 0.254 |
| 相対パワー4種類 | 0.443 |
| 相対パワー4種類＋Alpha/Theta比 | **0.488** |

今回比較した条件では、相対パワーとAlpha/Theta比を組み合わせた場合に、最も高いARIが得られた。

### 6.2 睡眠段階の移行とデルタ波の変化

N2からN3への移行は29回確認され、そのうち22回（75.9%）でデルタ波の相対パワーが増加した。

また、N3からN2への移行では、デルタ波の相対パワーが平均して減少する傾向が見られた。

### 6.3 睡眠前半・後半の比較

睡眠前半ではN3の割合が48.1%だったのに対し、後半では13.0%となった。

一方、覚醒（W）の割合は前半の0.3%から後半の18.6%に増加した。

## 7. 考察

今回の分析では、絶対パワーよりも相対パワーを使用した場合にARIが高くなった。

このことから、今回のデータでは、周波数帯域ごとのパワーの大きさだけでなく、帯域間の割合が睡眠段階の特徴を捉えるうえで有効だった可能性がある。

また、Alpha/Theta比の追加によってARIがさらに向上したことから、周波数帯域間の関係を特徴量として取り入れることにも一定の効果があったと考えられる。

一方、最も高いARIは0.488であり、睡眠段階を十分に区別できたとはいえない。

睡眠段階によって脳波の特徴が重なることや、使用した特徴量だけでは睡眠状態の違いを十分に捉えられないことが影響した可能性がある。

## 8. 今後の課題

今回の分析では、EEGの周波数特徴量を中心にクラスタリングを行った。

今後は、EOGやEMGなどの生体信号を組み合わせることや、時間的な変化を考慮することで、睡眠段階の特徴をより詳しく捉えられる可能性がある。

また、今回の結果がほかの被験者や記録でも再現されるか、追加の検証が必要である。
